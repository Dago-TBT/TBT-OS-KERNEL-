# 🌳 TBT OS — SISTEMA OPERATIVO DEL CONOCIMIENTO DEL BÉISBOL

Este repositorio contiene el código fuente, los documentos, los protocolos y los datasets del **Tree Baseball Theory Operating System (TBT OS)**.

## 📂 Estructura del Repositorio

- `/KERNEL`: Documentos fundacionales (DOC-00 a DOC-26).
- `/PROTOCOLS`: Protocolos experimentales y maestros.
- `/DATASETS`: Tablas y datasets históricos (Retrosheet, etc.).
- `/CODE`: Código fuente de los simuladores y motores.
- `/HISTORY`: Bitácora de decisiones y trazabilidad.

## 🔒 Estado Actual

- **Kernel:** Congelado (1.0 RC).
- **Master Protocol:** Congelado (v1.0).
- **Motores:** TCSE (Experimental), TQE (Especificación), PSE/BSE/OSE (Diseñados).
- **Dataset:** En construcción (Foundation Retrosheet).
